# 직업 데이터(고용24 Open API)

인증키는 서비스마다 따로 나온다. `.env.local`에 `WORK24_KEY_*`로 넣는다(`.env.example` 참고).

## 쓰는 곳

| API | 코드 | 쓰는 곳 |
|---|---|---|
| 채용정보 | `searchWanted` | 세계선 지도 '지금 현실에서는': 내 지역 신입 공고 수, 제시 연봉 가운데 값, 실제 공고 4개(링크) |
| 직업정보(상세) | `jobDetail` + `data/jobcodes.ts` | 재직자 연봉 분위·직업 만족도·5년 뒤 전망(재직자 응답) — 근거 자료 |
| 직무정보(표준직무기술서) | `dutiesFor` | 실제로 하는 일(NCS 능력단위) |
| 국민내일배움카드 훈련과정 | `trainingCourses` | 곧 열리는 국비 과정과 6개월 취업률('국비 교육' 갈림길의 근거) |
| 학과정보 | `searchMajors` | 전공 이름 → 표준 학과명 → 진로 추천 정확도 |
| 구직자취업역량 강화프로그램 | `centerPrograms` | 리포트: 지금 신청할 수 있는 고용센터 프로그램 |
| 공통코드 | `regionCodes` | 사는 곳 → 고용24 지역코드 |

화면에서는 실시간으로 부르고(6시간 캐시), 발표용으로는 미리 받아 둔다.

```bash
npx tsx@4.19.2 --tsconfig tsconfig.json scripts/sync-jobdata.ts
```

- `extra-facts.json`: 진로별 근거 자료에 자동으로 붙는다(출처 '고용24 …'인 항목만 매번 새로 바뀌고, 손으로 넣은 항목은 남는다).
- `market.json`: 진로별 신입 공고 수·제시 연봉 가운데 값. **지금은 비어 있다**(채용정보 API가 개인회원 키로는 막혀 있음. 기관 키를 받으면 채워진다).

## 아직 확인이 필요한 것

- 채용정보는 개인회원 키로 호출이 막혀 있다(기관 키 필요). 그래서 `minSal`이 원 단위인지 만원 단위인지 문서에 없어서 크기로 판단한다(`lib/work24.ts`의 `toAnnualMan`). 실제 응답을 보고 확인할 것.
- 직업정보 상세는 `callOpenApiSvcInfo212D04.do`(target=JOBDTL, jobGb=1, dtlGb=4)로 2026-10-30 실제 응답을 확인했다. 연봉은 **재직자 전체(경력 포함)** 분위라서 신입 연봉이 아니다. 전망 서술은 2016년 자료 인용이라 쓰지 않고 재직자 응답 비율만 쓴다.
- 이름 검색은 엉뚱한 직업이 먼저 나와서(마케터 → 텔레마케터) 진로별 직업코드를 `data/jobcodes.ts`에 정해 두었다. 예전의 '연봉 구간 조건 검색'은 코드 뜻을 확인할 수 없어 뺐다.
- 공고 수는 '일자리가 얼마나 있나'이지 '붙을 확률'이 아니다. 확률 보정에는 경쟁률 자료가 따로 필요하다.
