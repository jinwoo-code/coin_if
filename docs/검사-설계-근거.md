# 검사 설계 근거

이 앱은 성격 검사 하나만으로 사람을 판정하지 않는다. 자기 보고, 실제 행동, 인생 이야기를 함께 써서 '나를 닮은 분신'을 만든다. 그리고 그 분신이 나를 얼마나 닮았는지 직접 재서 보여 준다. 선택은 규칙 엔진이 정하고, AI는 문장만 쓴다. 아래는 이렇게 설계한 이유와 근거가 된 연구다.

(원본: 팀 문서 「검사 설계 근거」 PDF. 저장소에 옮기면서 맨 끝에 '발표 후 할 일'을 더했다.)

## 네 가지 원칙

| 원칙 | 왜 | 근거 |
|---|---|---|
| 1. 성격을 '맞히는' 게 아니라 '분포'로 다룬다 | 같은 사람도 상황마다 다르게 행동한다. 그래서 성격을 고정값이 아니라 평균과 흔들림 폭이 있는 분포로 본다. 선택은 확률로 뽑고, 같은 인생을 100번 산다. | Fleeson의 전체 특성 이론(Whole Trait Theory) |
| 2. 여러 출처를 겹친다 | 자기 보고만 쓰면 '되고 싶은 나'가 섞인다. 인터뷰·설문·실제 행동을 함께 쓸 때 가장 정확하다. | Park 외(2024): 인터뷰로 만든 분신이 인구통계만 쓴 분신보다 정확했다. Youyou 외(2015): 행동 기록으로 본 성격이 가족의 판단보다 정확했다. |
| 3. 선택은 규칙 엔진이, 문장은 AI가 | LLM에게 '이 사람이라면 뭘 고를까'를 맡기면 고정관념을 따르고, 실제보다 지나치게 합리적인 답을 낸다. | 컬럼비아대 연구(2025): AI 분신에서 다섯 가지 체계적 왜곡이 나왔고, 개인 단위 상관은 약 0.2였다. |
| 4. 정확도는 주장하지 않고 측정한다 | '정확하다'고 말하는 대신, 분신이 내 실제 답을 몇 % 맞히는지 매번 재서 보여 준다. | Park 외(2024)의 평가 방식: 본인이 다시 답했을 때의 일관성과 비교한 정확도 |

성격이 인생 결과에 영향을 주는 건 맞지만, 그 크기는 작다. Soto(2019)가 성격과 인생 결과의 관계 78개를 다시 검증했더니 87%가 재현됐다. 하지만 63~71%는 효과가 원래 보고보다 작았다. 그래서 엔진에서 성격 가중치는 작게 두고, 스펙·생활 조건·운이 결과를 더 크게 좌우하게 했다.

## 검사 구성

모든 것을 검사 하나로 재지 않는다. 재는 대상마다 가장 잘 맞는 방법을 골랐다.

| 재는 것 | 방법 | 엔진에서 쓰는 곳 | 왜 이 방법인가 |
|---|---|---|---|
| 성격 5요인 | BFI-10(기본), IPIP 50문항(정밀) | 선택 성향, 시험 공부량 | 국제적으로 검증된 척도다. 10문항은 빠르지만 특성당 2문항이라 오차가 크다. 그래서 50문항을 따로 둔다. |
| 실제 행동 성향(끈기·위험 감수·회복·도움 요청) | 상황 질문 | 재도전·포기·이직 갈림길 | '이 상황이면 뭘 할지'를 묻는 게 자기 보고보다 실제 행동에 더 가깝다. |
| 가치관 | 8개 중 4개 순위 | 선택 이유, 직업 만족도 기준 | 같은 결과라도 가치관에 따라 만족이 다르다. |
| 직업 흥미 | 홀랜드 6유형 간이 24문항(커리어넷 공인 검사로 교체 예정) | 진로 추천, 부합도 | 진로 상담에서 쓰는 표준 모델이다. |
| 현실 조건 | 스펙·생활 조건 입력, 이력서 PDF | 합격 확률, 돈 흐름, 입대·졸업 시기 | 성격보다 결과를 더 크게 좌우한다(Soto, 2019). |
| 인생 이야기 | AI 반구조화 인터뷰(진로 구성 인터뷰 방식) | 결정 방식·가족 기대·후회 유형 → 선택 보정. 대화 말투와 기억에도 쓴다. | 인터뷰로 만든 분신이 가장 정확했다(Park 외, 2024). 인생 이야기는 성격 점수가 못 잡는 부분을 채운다. |
| 앱 안 실제 선택 | '나라면 이렇게 안 해' 보정, 한 달 뒤 체크인 | 선택 가중치 보정 | 행동 기록이 자기 보고보다 정확하다(Youyou 외, 2015). |

## 검사 깊이: 사용자가 고른다

빠르게 끝내고 싶은 사람은 10분, 정확하게 하고 싶은 사람은 몇 시간이든 할 수 있게 했다. 깊이를 바꿔도 같은 엔진을 쓴다. 알려 준 만큼만 분신이 정확해진다.

| 단계 | 시간 | 내용 |
|---|---|---|
| 빠르게 | 약 10분 | AI 인터뷰, 성격 10문항, 상황 질문, 스펙·생활 조건 |
| 표준 | 30~40분 | 빠르게 + 성격 50문항, 흥미 검사, 인생 이야기 핵심 질문 |
| 정밀 | 장별로 여러 번, 합쳐서 1~2시간 이상 | 인생 이야기 6장(어린 시절·학창 시절·가족과 집·일과 활동·큰 결정과 후회·가치관과 미래), 장마다 AI 꼬리 질문 |
| 계속 닮아 가기 | 몇 주~몇 달 | 시뮬레이션 속 선택 보정, 한 달 뒤 체크인 |

### 왜 이렇게 나눴나

- 스탠퍼드 1,000명 연구는 한 사람당 약 2시간씩 인터뷰했다. 정밀 단계는 이 수준을 목표로 한다.
- 한 자리에서 몇 시간을 하면 뒤로 갈수록 답이 대충이 된다. 그래서 15~20분짜리 장으로 나누고, 멈췄다가 이어서 할 수 있게 했다.
- 같은 연구에서 인터뷰와 설문을 합쳤을 때 정확도가 가장 높았다. 하지만 오른 폭은 작았다. 인터뷰가 한두 시간을 넘으면, 인터뷰를 더 하는 것보다 실제 행동 데이터를 모으는 쪽이 정확도를 더 올린다고 본다. 그래서 '계속 닮아 가기' 단계를 두었다.
- 20~30대는 성격이 변하는 시기다. 청년기에는 성실성과 정서 안정성이 평균적으로 오른다(Roberts 외, 2006). 그래서 한 번 잰 성격을 계속 쓰지 않고, 체크인으로 다시 맞춘다.

## 닮은 정도 측정: 입력 개수가 아니라 실제로 맞히는지

지금 화면의 '정밀도'는 몇 개를 입력했는지 세는 값이다. 많이 입력했다고 분신이 나를 닮았다는 보장은 없다. 그래서 분신이 내 선택을 실제로 맞히는지 재서 보여 주는 방식으로 바꾼다.

### 방법

1. 상황 질문 몇 개는 시뮬레이션에 쓰지 않고 따로 떼어 둔다(시험용).
2. 분신에게 같은 상황을 주고 답을 고르게 한 뒤, 내가 실제로 고른 답과 비교한다.
3. 맞힌 비율을 "분신이 내 선택을 ○% 맞혀요"로 보여 준다.
4. 검사 단계를 하나 끝낼 때마다 다시 잰다. 예: 빠르게 61% → 표준 74% → 정밀 81%(예시 숫자이고, 아직 실측 전이다).

### 근거

- 스탠퍼드 1,000명 연구(Park 외, 2024)는 분신의 정확도를 '본인이 2주 뒤 같은 질문에 다시 답했을 때 일치하는 정도'로 나눠서 쟀다. 사람도 자기 답을 100% 똑같이 되풀이하지 못하기 때문이다. 우리도 같은 생각으로, 시험용 질문 일부를 2주 뒤 본인에게 다시 물어 기준선을 잰다.
- 결과가 낮게 나오면 그대로 보여 준다. 그래야 사용자가 검사를 더 할지 스스로 정할 수 있다.

## 인생 이야기: 성장 배경을 묻는 이유

성격 점수만으로는 '왜 그렇게 고르는지' 알기 어렵다. 성실성 점수가 같아도, 집안 형편 때문에 버티는 사람과 좋아서 버티는 사람은 다르게 움직인다. 인생 이야기가 설문 점수보다 행동을 더 잘 설명한다는 연구가 있다(내러티브 정체성의 증분 타당도, PubMed 25968138).

### 핵심 질문: 진로 구성 인터뷰(Savickas) 5문항

1. 어릴 때 존경했던 사람은 누구이고, 어떤 점이 좋았나요?
2. 즐겨 보는 콘텐츠(유튜브, 웹툰, 잡지 등)는 뭔가요?
3. 좋아하는 이야기(책, 영화, 드라마)는 뭔가요?
4. 좌우명이나 자주 떠올리는 말이 있나요?
5. 가장 오래된 기억은 뭔가요?

진로 상담에서 널리 쓰는 질문이라 근거가 있고, 짧아서 '표준' 단계에 넣을 수 있다.

추가 질문(정밀 단계): 지금까지 내린 큰 결정, 끝까지 해 본 것과 그만둔 것, 가족이 기대하는 것, 가장 후회하는 선택, 집안 형편과 집에서 지원받을 수 있는 기간.

### 이야기에서 뽑는 값과 엔진에서 쓰는 곳

| 이야기에서 뽑는 것 | 엔진에서 쓰는 곳 |
|---|---|
| 결정 방식(충동 / 신중 / 남 따라) | 갈림길에서 고르는 성향(push/change/safe) |
| 끈기(끝까지 해 본 경험, 그만둔 경험) | persistence 배수 |
| 가족 기대 | 안정 직업 쪽 선택 가중치 |
| 후회 유형(안 해서 / 해서) | 도전 쪽 선택 가중치 |
| 핵심 가치 | 가치관 부합도, 직업 만족 |
| 버틸 수 있는 기간 | 생활비 바닥 갈림길 시점 |

### 왜 원문을 그대로 넣지 않고 값으로 뽑나

- 스탠퍼드 연구는 인터뷰 원문 전체를 AI에게 넣었다.
- 하지만 컬럼비아 연구(2025)에 따르면 AI 분신이 개인을 맞히는 상관은 약 0.2에 그쳤다. 사람을 실제보다 더 일관되고 극단적으로 그리는 왜곡도 보고됐다. 페르소나가 많아질수록 서로 비슷해지는 현상도 있다(2026).
- 그래서 결정은 엔진이 구조화된 값으로 하고, 원문은 대화와 이야기 문장에만 쓴다. 원칙 3(숫자는 엔진, 문장은 AI)과 같은 이유다.
- 이렇게 하면 선택 이유에 내 이야기가 드러난다. 예: "고3 때 하고 싶은 걸 포기한 걸 후회한다고 해서 이번엔 도전했어요."

## 한계와 개인정보

### 정직하게 밝히는 한계

- 사람의 선택을 완벽하게 예측할 수는 없다. 가장 잘 만든 분신도 본인이 다시 답한 것과 비교해 83~86% 수준이다(Park 외, 2024).
- 20~30대는 성격이 변하는 시기다(Roberts 외, 2006). 10년 시뮬레이션에서 지금 성격을 그대로 쓰면 뒤로 갈수록 틀릴 수 있다.
- 성격 10문항(BFI-10)은 짧아서 오차가 크다. 그래서 50문항과 인생 이야기를 선택 항목으로 두었다.
- IPIP 50문항은 우리가 직접 번역했고, 흥미 24문항은 직접 만든 간이 검사다. 커리어넷 공식 검사로 바꿀 예정이다.
- 성격과 삶의 결과 사이 관계는 재현 연구에서 87%가 다시 확인됐다. 하지만 효과 크기는 원래 보고보다 작았다(Soto, 2019). 그래서 성격이 진로를 정하는 힘을 과장하지 않는다.

### 개인정보 원칙

- 모든 질문은 건너뛸 수 있고, 시작 전에 동의를 받는다.
- 인생 이야기 원문은 본인만 본다. 언제든 지울 수 있다.
- 대학 관리자에게는 통계만 보여 주고, 학생 개인 기록은 보여 주지 않는다.
- 이야기 중 위기 신호(자해·자살 관련 말)가 나오면 상담 연락처를 안내한다.
- 학생 데이터가 AI 학습에 쓰이지 않도록 실제 학생이 쓰는 곳에는 유료 API 키만 쓴다(개발은 가상 데이터로 무료 키 사용, CLAUDE.md 결정 기록 참고).
