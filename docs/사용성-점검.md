# 사용성 점검(휴리스틱 평가)

- 날짜: 2026-11-07~08
- 대상: 배포본 https://coinif.vercel.app (main, `/api/status` 기준 `tier: free`)
- 방법: Playwright(로컬 Chrome), iPhone 13 에뮬레이션 390×844. 화면 판단은 보이는 글자와 스크린샷만으로 했다.
- 사람: A 경영학과 2학년(진로 모름, 빠르게) / B 간호학과 3학년(간호사 vs 공무원, 표준) / C 예시로 둘러보기(김민준 → 이서연 → 체크인)
- 스크린샷: `docs/screens/usability/` (사람-번호-화면.png, 전체 페이지, 390px로 줄임). F-*는 실패 상태를 일부러 만든 화면.
- 로그인·결제: 운영 주소라서 로그인과 결제 입력은 하지 않았다(로그인·토큰 화면은 글자만 봤다). 토큰 화면에 "테스트 결제예요. 실제로 돈이 나가지 않아요."가 보인다.

## AI 호출 수

요청 기준 47번(분신 판단 32 · 서술 5 · 리포트 6 · 검사 요약 3 · 이야기 정리 1, 실패 상태 시험 4번 포함). 한도에 걸리지 않아 '한도 화면'은 못 봤다. 대신 판단·서술 API를 500으로 막아 실패 화면을 봤다(4번 항목).

- 첫 화면에서 할 일 두 개(인터뷰 / 예시)가 분명하고, 예시 고르기 창에 "가상 인물, 로그인 없이"가 적혀 있다.
- 검사 상단 진행 숫자(4/13 등)와 점선 진행 막대가 '지금 어디'를 보여 준다.
- 지도 맨 위 카드에 '3년 안에 취업 88%'가 크게 있어 3초 안에 답이 보인다. 리포트도 맨 위에 '가장 가까운 길 66점'.
- 다시 연 화면은 0.1~1.2초. 리포트는 다시 열어도 AI를 다시 안 부른다(같은 기기).
- 15px 미만 본문은 거의 없다(13px 보조 글만, 12px은 34번뿐).

## 지워야 할 것

- 로그인하지 않아서 계정 데이터(Supabase 프로필·시뮬레이션·토큰 원장)는 만들지 않았다. 서버로 간 건 `/api/sync`·`/api/tokens` 읽기(GET)뿐.
- 공유 링크는 만들지 않았다. `?pilot=1`은 쓰지 않았다.
- 시뮬레이션·리포트·검사 요약·이야기 정리 요청으로 가상 인물 A·B의 답(가상 이름 '가나다', 직접 쓴 이야기 5문장)이 배포본의 Gemini(무료 등급) 호출로 나갔다. 실제 사람 정보는 아니다.
- 브라우저 저장은 점검용 Playwright 프로필에만 있다(작업 컴퓨터의 임시 폴더, 점검 뒤 지움).
