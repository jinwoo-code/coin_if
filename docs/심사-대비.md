# 심사 대비: 한계와 답변

기준일 2026-11-06. **한 줄 입장: "아직 효과를 증명하지 못했습니다. 대신 무엇을 모르는지 화면에 적고, 재는 도구까지 만들었습니다."** 없는 근거를 있는 것처럼 말하지 않습니다.

## 예선 총평 세 가지

### 1. "개인차를 AI가 다 알 수 없다"

**답: 맞습니다. 그래서 AI에게 다 맡기지 않습니다.**

- AI는 갈림길에서 보기별 확률만 말합니다. 사건·합격·돈은 엔진이 계산합니다.
- AI 판단은 기준 비율에서 오즈 0.67~1.5배 안에서만 반영합니다. AI가 극단으로 말해도 결과가 뒤집히지 않습니다.
- 분신이 나를 닮았는지 따로 잽니다. 학습에 안 쓴 상황 질문으로 맞힌 개수를 보여 줍니다. 빠르게는 3문항, 표준은 6문항이라 우연이 크다는 것도 같이 말합니다.
- 틀리면 사용자가 '나라면 이렇게 안 해'로 고치고, 한 달 체크인으로 다시 맞춥니다.
- 결과는 한 줄 예언이 아니라 1,000번의 분포와 표본 오차 범위입니다.

**인정할 것:** AI와 규칙은 셋 중 하나꼴로 반대 방향이었고(5명 × 8곳), 어느 쪽이 맞는지 아직 모릅니다. 비교 스크립트는 있지만 실제 사람 데이터로 돌린 적이 없습니다.

### 2. "현직자·학생 변화의 근거가 있는가"

**답: 지금은 없습니다. 현직자 인터뷰 0명, 파일럿 참여자 0명입니다. 모을 도구는 준비됐습니다.**

| 근거 | 지금 | 준비된 것 |
|---|---|---|
| 현직자 | 기준 비율 보기 1,900개 중 현직자 값 0개 | 인터뷰 질문지. 값이 들어오면 화면 등급이 '현직자 N명'으로 바뀝니다 |
| 학생 변화 | 측정 전 | 파일럿 사용 전·후 설문(확신도, 고려 중인 진로, 이번 주 할 일)과 자유 답, 집계 스크립트 `scripts/pilot-report.ts` |
| 행동 변화 | 측정 전 | 한 달 체크인 화면(자기 일치율, 지난 한 달 실제 선택) |

**인정할 것:** 전·후 설문은 비교 집단이 없는 자기 보고이고 참여자는 자원자입니다. 숫자가 좋아져도 앱 덕분이라고 말할 수 없고, 확신이 오른 것이 좋은 결정이라는 뜻도 아닙니다. 첫 목표는 효과 증명이 아니라 "실제로 판단이나 행동이 달라지는 사람이 있는가"입니다.

### 3. "신뢰도·효과를 어떻게 검증하는가"

**답: 재현성과 통계 대조는 했습니다. 예측 정확도와 효과는 아직 검증하지 못했습니다.**

| 항목 | 상태 | 숫자 |
|---|---|---|
| 재현성 | 확인 | 같은 입력이면 같은 결과(시드 고정, 자동 테스트) |
| 공개 통계 대조 | 일부 진로 | 9급 합격자 평균 20.3개월(통계 20개월), 2년 안 77%(통계 73.3%). 개발자 10.6개월(청년 전체 첫 취업 11.2개월, 대상이 다름) |
| 민감도 | 확인 | 가중치를 하나씩 0·0.5·2배로 바꿈. 가장 크게 움직이는 것은 준비도 배수(합격률 최대 ±15~27%p) |
| 가중치 근거 | **대부분 가정값** | 81개 중 80개가 가정값, 9급 통계로 추정한 값 1개, 사람 답으로 보정한 값 0개 |
| 기준 비율 근거 | **대부분 가정값** | 보기 1,900개 중 통계 1개(그것도 다른 집단 기준), 나머지는 평균 인물로 잰 값 |
| 사람 예측 정확도 | 미검증 | 보정 방법은 가상 응답자로만 확인. 파일럿 30명이면 2배쯤 틀린 값만 잡힙니다 |
| 사용 효과 | 미검증 | 위 파일럿 전·후 설문이 첫 단계 |

**검증 순서:** ① 파일럿 30명 전·후 설문과 상황 질문 ② 가중치 일부 보정, 비교 집단 교체 ③ 간호사·초등교사 현직자 인터뷰 ④ 청년패널 원자료로 합격·취업 배수 분석(신청 전). ④ 없이는 합격률을 크게 움직이는 배수를 보정할 수 없습니다.

## 나올 만한 질문

| 질문 | 답 |
|---|---|
| 합격률 숫자를 믿어도 되나요? | 예측이 아니라 "이 가정이면 이렇게 된다"는 비교용입니다. 가정값은 화면에 표시하고 보장하지 않는다고 적었습니다. |
| 왜 챗봇이 아니라 시뮬레이션인가요? | AI가 숫자를 지어내면 근거를 댈 수 없습니다. 숫자는 엔진이, 말은 AI가 맡아 같은 입력에 같은 결과가 나옵니다. |
| 진로마다 깊이가 같나요? | 아닙니다. 53개 중 4개만 손으로 쓴 상세판이고 49개는 유형 공통 사건이라 더 얕습니다. |
| 공고 데이터가 있나요? | 없습니다. 고용24 채용정보는 개인 키로 안 되어 기관 키가 필요합니다. 화면에 "공고 집계 없음"으로 적었습니다. |
| 자격증 추천은 맞나요? | 공식 목록에서만 고릅니다. 관련 없는 자격은 팀이 뺐지만 현직자 확인 전입니다. 시뮬레이션에 안 들어가는 자격은 효과를 지어내지 않습니다. |
| 성격 검사는 검증됐나요? | Mini-IPIP·IPIP 50은 공개 문항이지만 번역은 자체라 한국어 타당도를 재지 않았습니다. 비교 평균도 미국 청년 표본입니다. 흥미 24문항과 상황 질문은 팀이 만들었습니다. |
| 개인정보는요? | 인생 이야기 원문은 이 기기에만 남고, 공유본에는 정해 둔 칸만 들어갑니다. 실제 학생을 받기 전에 Gemini를 유료 키로 바꿔야 합니다. 동의서는 아직 초안이고 법률 검토 전입니다. |
| 원가와 수익은요? | 학생 1명 1회 약 52원(2026 단가, 실측 토큰 기준). 손익분기는 대학 약 6.2곳이고 실제 흑자는 7곳부터입니다. 모두 가정한 계약 금액 기준입니다. |

## 하면 안 되는 말

- "정확도 ○○%", "AI가 당신의 미래를 예측합니다", "합격을 도와줍니다"
- "실시간 판단 모드가 더 정확합니다"(근거 없음)
- "학생들에게 효과가 있었습니다"(파일럿 결과가 나오기 전)
- "현직자가 검증했습니다"(0명)
