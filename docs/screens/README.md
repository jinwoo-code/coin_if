- 찍은 곳: 배포 사이트 https://coinif.vercel.app (커밋 `964d2b7`, 2026-11-06~07). 목업이 아니라 실제 AI 응답이고, 무료 등급 키입니다.
- 폭: `390/`(모바일 에뮬레이션), `1280/`. 배율 1.
- 긴 화면은 전체 페이지로 찍었고, 사진에서만 하단 고정 버튼을 본문 흐름 안에 넣었습니다. 실제 화면에서는 버튼이 아래에 붙어 있습니다.
- 인물은 가상 시연 인물(김민준)과 테스트 프로필입니다. 실제 학생 데이터는 없습니다.
- 다시 찍기: `DOCS_SCREENS=1 BASE_URL=https://coinif.vercel.app E2E_SHARE_DB=1 npx playwright test e2e/docs-screens.spec.ts` (약 7분)
