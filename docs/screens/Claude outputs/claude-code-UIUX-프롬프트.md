UI·UX를 개선해 줘. 기준은 "처음 쓰는 학생이 설명 없이 끝까지 간다"야. 이번 작업은 배치·문구·접기만 바꾸고 기능·계산·데이터는 바꾸지 마. `docs/UI-UX-개선-목록.md`가 있으면 먼저 읽어(없으면 아래 내용이 전부야).

main에서 `uiux-polish` 브랜치를 따서 작업해. 항목마다 커밋하고 push. 단계마다 빌드와 전체 e2e를 돌리고, 바꾼 화면의 390px·1280px 전후 스크린샷을 `docs/screens/after/`에 남겨. e2e가 문구 변경 때문에 깨지면 테스트를 고치되, 기능 검사를 약하게 만들지는 마.

## 원칙

1. 화면마다 맨 위에 "그래서 나는?"의 답(결론)을 두고, 근거·숫자·상세는 접어 둔다('자세히').
2. 가정값·오차 범위·근거 등급은 없애지 말고 '자세히' 안으로 옮긴다. 정직하게 공개하는 건 그대로 유지.
3. 전문 용어는 화면에서 쉬운 말로. 용어는 `lib/copy.ts` 같은 한 파일에 모아서 나중에 한 번에 바꿀 수 있게 해.

## 1단계: 시연 전 꼭 고칠 것

1. **시뮬레이션 화면 줄이기** (지금 휴대폰에서 약 5,700px)
   - 맨 위에 요약 카드: 취업(합격) 시기, 끝날 때 만족도, 모은 돈, 연봉.
   - 타임라인은 연도별로 접고, 펼치지 않아도 그해의 큰 사건(취업, 이직, 합격, 번아웃 등) 1~2줄만 보이게.
   - 수치 변화(+30 등), 선택 이유, '보통 N% → 나 M%'는 사건을 눌러야 펼쳐지게. 단 '보통 → 나' 표시는 지우지 마.
   - 목표: 접힌 상태에서 휴대폰 기준 2,000px 안팎.
2. **리포트 줄이기** (지금 약 6,500px)
   - 리포트는 결론(맞는 길과 이유)과 행동(이번 주 할 일, WOOP, 실행 계획)만 펼쳐 둔다.
   - '1,000번 결과'는 세계선 지도와 겹치니 요약 한 줄 + "갈래 길 지도에서 자세히 보기" 링크로.
   - 프리미엄 미리 보기와 고용센터 프로그램은 접어 둔다.
3. **용어 바꾸기** (화면 문구만, 코드 변수명은 그대로)
   - 본선 → 가장 흔한 길
   - 세계선 → 갈래 길, 세계선 지도 → 갈래 길 지도 (※ 이건 팀 확정 전이라 `lib/copy.ts`의 상수 하나로 바꿀 수 있게만 해 두고, 기본값은 지금 표현 유지 + 첫 등장 때 한 줄 설명 "1,000번 중 비슷하게 흘러간 삶을 묶은 것")
   - 브라이어 점수 → 화면에서 빼고 "N개 중 M개 맞힘"만. 브라이어는 '자세히'에
   - 95% 신뢰구간 → 오차 범위
   - ×1.23 같은 배수 → "보통보다 조금 유리해요/불리해요" + 자세히에 배수
   - 가정값 → "우리가 정한 값(아직 데이터 없음)"
   - 실시간 판단 모드 → "AI가 직접 살아 보는 모드"
4. **시연·내부 문구 숨기기**
   - "(시연용으로 지금도 돼요)" 같은 시연 전용 문구는 예시 인물일 때만.
   - 파일럿 관련 카드·문구는 파일럿 참여자에게만.
   - "개인정보 처리방침(초안)"의 '(초안)'은 그대로 둬(확정 전이라). 대신 첫 화면 푸터에서는 "개인정보 처리방침"으로만 보이고 처리방침 페이지 안에 초안 표시.
5. **진로 고르기 화면 정리**
   - 맨 위 카드 3개(한 달 체크인, 파일럿 상황 질문, 더 정확하게 하기)를 '내 정보' 메뉴(또는 검사 결과 화면)로 옮겨. 진로 고르기 화면은 검색 → 추천 목록 → 기간 → 모드 → 시작만.
   - 빨간 '전체 지우기'는 설정/내 정보로 옮기고, 누르면 확인 창.
6. **첫 화면 예시 지도**: 개발자·공무원·데이터 분석가 대신 계열이 섞인 예시(예: 간호사·초등교사·시각 디자이너)로. 실제 시뮬레이션 데이터가 아니라 그림이면 "체험 예시" 표시 유지.

1단계 끝나면 전체 e2e와 스크린샷 전후 비교를 보여 주고, 내가 확인한 뒤 2단계.

## 2단계: 시간 되면

7. **첫 화면 버튼**: 주 버튼 "인터뷰로 시작하기" + 보조 버튼 "예시로 둘러보기" 둘만. 예시를 누르면 인물(경영학과 김민준, 간호학과 이서연)을 고르는 창.
8. **검사 스펙 입력**: 두 화면으로 나누거나(학교·학점·어학 / 자격증·경험), '나중에 채우기' 버튼. 자격증 칩은 전공 관련 상위 6개만 보이고 '더보기'.
9. **검사 결과**: 요약 문장이 잘리지 않게(전문 표시 또는 더보기). 성격 그래프 아래에 요인별 한 줄 설명("성실성: 또래보다 높은 편"). 비교 집단이 가정값이면 그렇게 표시.
10. **가독성**: 본문 최소 15px(보조 텍스트 13px), 회색 글자 대비 4.5:1 이상(WCAG AA). 대비가 안 맞는 곳 목록을 먼저 보여 줘.

## 건드리지 말 것

- 갈래 길 지도의 "85% (83~87%) · 보통 2027년 9월" 표시 방식
- '내가 바꿀 수 있는 것 Top 3'의 전후 비교(취소선 → 새 숫자)
- 검사 깊이 고르기 카드, 대화형 검사 흐름
- 근거 자료 접기, 근거 등급 배지, '보통 N% → 나 M%'
- 진로별 색, 하단 고정 버튼, 카드 모양
- 마지막의 '진로를 한눈에 비교해요' 표

## 보고

단계가 끝날 때마다:
- 바꾼 항목, 커밋 해시
- 화면 길이 전후(휴대폰 px)
- e2e 결과
- 판단이 애매했던 것(예: 어떤 숫자를 접을지) 목록
